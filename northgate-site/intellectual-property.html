Research & intellectual property

Three directions on one problem.

How should trust be established, continuously reassessed, and translated into enforceable authority as humans, devices, and autonomous systems interact?

Northgate Cryptography's research program examines that question from three directions. The resulting work has produced three related pending U.S. patent families.

Family 1 · Autonomous-agent authorization

Continuous Trust-Signal-Based Constraint of AI Agent Authorization Through Artifact Mutation and Velocity-Triggered Enforcement

  • delegated AI-agent authority
  • continuous authorization
  • authorization-artifact mutation & revocation
  • permission-tier adjustment
  • multi-agent delegation
  • pre-execution policy enforcement
  • fail-secure degradation
  • rate-of-change security triggers
  • cryptographically attributable audit records

The architecture explores how an agent's effective authority can remain dependent on the current verified state of the originating human or organizational authority, rather than remaining fixed solely at the time of delegation.

Family 2 · Continuous identity assurance

Neural Intelligence System for Continuous Biometric Authentication Within Zero Trust Security Architecture

  • continuous session authentication
  • risk-adaptive thresholds
  • on-device biometric processing
  • derived biometric representations
  • dynamic privilege adjustment
  • least-privilege enforcement
  • liveness / presentation-attack detection
  • step-up authentication
  • session-bound identity assurance
Family 3 · Multimodal security & deception analysis

Neural Intelligence System for Social Networking Applications, Multi-Platform Biometric Security, and AI-Powered Deception Detection

  • multimodal biometric analysis
  • facial geometry
  • behavioral patterns
  • cross-platform identity consistency
  • NLP-based deception indicators
  • metadata / image analysis
  • aggregate risk scoring
  • adaptive security responses

These applications should not be interpreted as claims that any particular third-party product, government framework, or implementation practices the patent claims. References to external developments are provided only to examine the evolution of the broader security problem space.
